** Containers
*** Freebsd
**** Load geli Support

Support for geli is available as a loadable kernel module. To configure the system to automatically load the module at boot time, add the following line to /boot/loader.conf:

#+BEGIN_SRC sh
geom_eli_load="YES"
#+END_SRC

**** create the mount point

#+begin_src sh
mkdir -p ~/mnt
#+end_src

**** create virtual container with dd

create a 128mb container with dd called disk.img

use dd to create a 128mb disk image

#+BEGIN_SRC sh
dd if=/dev/zero of=disk.img bs=1M count=128
#+END_SRC

**** mount the image with mdconfig

use mdconfig to mount the disk image

#+BEGIN_SRC sh
doas mdconfig -a -t vnode -f disk.img -u 0
#+END_SRC

Here, the -a option forces the disk mounting, -t vnode is used for opening a regular file, and the path of this file is specified after -f. The -u 0 option set the virtual disk identifier to use, in this case /dev/md0.

**** Generate the Master Key

create directory to store geli key

#+BEGIN_SRC sh
mkdir -p ~/.config/ossuary
#+END_SRC

Now we want to create a key for GELI to encrypt with, and attach it to our disk image device:

#+begin_src sh
dd if=/dev/zero of="${HOME}/.config/ossuary/ossuary.key" bs=256 count=1
#+end_src

#+begin_src sh
doas geli init -e aes -l 256 -s 4096 -K "${HOME}/.config/ossuary/ossuary.key" /dev/md0
#+end_src

#+BEGIN_SRC sh
geli attach -k "${HOME}/.config/ossuary/ossuary.key" /dev/md0
#+END_SRC

Enter passphrase:

**** Create the ZFS File System

Next, format the device with the ZFS file system and mount it on an existing mount point:

+ use dd to write random data to geli container before adding file system

#+BEGIN_SRC sh
doas dd if=/dev/random of=/dev/md0.eli bs=1M
#+END_SRC

+ To create a simple, non-redundant pool using a single disk device:

#+BEGIN_SRC sh
doas zpool create crypt /dev/md0.eli
#+END_SRC

+ add compression and duplication to the zfs pool

#+BEGIN_SRC sh
doas zfs set compression=lz4 crypt
#+END_SRC

+ zfs set mount point

#+BEGIN_SRC sh
doas zfs set mountpoint="${HOME}/mnt" crypt
#+END_SRC

+ change the permission on the container

#+BEGIN_SRC sh
doas chown -R "${USER}:${USER}" "${HOME}/mnt"
#+END_SRC

+ chmod the ~/mnt directory

#+begin_src sh
chmod 700 ~/mnt
#+end_src

Finally, when you want to unmount, we also want to detach from GELI and detach from md:

+ zfs unmount

#+BEGIN_SRC sh
doas zfs umount crypt
#+END_SRC

+ zpool export

#+begin_src sh
doas zpool export crypt
#+end_src

+ geli detach

#+BEGIN_SRC sh
doas geli detach md0.eli
#+END_SRC

+ mdconfig free loop device

#+BEGIN_SRC sh
doas mdconfig -d -u 0
#+END_SRC

**** manually mounting and unmounting
***** mount

use mdconfig to mount the encrypted container to /dev/md0

#+BEGIN_SRC sh
doas mdconfig -a -t vnode -f disk.img -u 0
#+END_SRC

+ use geli with the path to the key and device

#+BEGIN_SRC sh
doas geli attach -k /home/djwilcox/.config/ossuary/ossuary.key /dev/md0
#+END_SRC

+ we need to import the zpool which will also mount the container

#+BEGIN_SRC sh
doas zpool import crypt
#+END_SRC

unmount the zfs pool

#+BEGIN_SRC sh
doas zfs umount crypt
#+END_SRC

#+BEGIN_SRC sh
doas zpool export crypt
#+END_SRC

+ use geli to detach the encrypted device

#+BEGIN_SRC sh
doas geli detach md0.eli
#+END_SRC

+ free the loop device

#+BEGIN_SRC sh
doas mdconfig -d -u 0
#+END_SRC
	
*** Linux
**** luks encrypted container
***** create a container wth dd called crypt

create a 128mb disk image

#+begin_src sh
dd if=/dev/urandom of=crypt bs=1M count=128
#+end_src

***** rename the file and give it a file extension to disguise it

#+begin_src sh
mv crypt disk.iso 
#+end_src

***** find a free loop device to mount the file

#+begin_src sh
doas losetup -f
#+end_src

the free loop device is /dev/loop0 in this case
if you have a different free loop device use that number

***** use the block device and the path to the file you just created

#+begin_src sh
doas losetup /dev/loop0 disk.iso
#+end_src

create the luks container inside the file
you will be prompted to enter a password for the new luks container

#+begin_src sh
doas cryptsetup luksFormat /dev/loop0
#+end_src

***** check the file is now an encrypted luks container

#+begin_src sh
file disk.iso
#+end_src

map the luks container to the loop device
and give it a luks alias in this case luks

#+begin_src sh
doas cryptsetup luksOpen /dev/loop0 luks
#+end_src

***** format the container as ext4

#+begin_src sh
doas mkfs.ext4 /dev/mapper/luks
#+end_src

***** mount the file

#+begin_src sh
mkdir -p ~/mnt
#+end_src

#+begin_src sh
doas mount /dev/mapper/luks ~/mnt
#+end_src

***** change ownership on container to the current user

#+begin_src sh
cd ~/mnt
#+end_src

nixos

#+begin_src sh
doas chown -R ${USER}:users .
#+end_src

debian

#+begin_src sh
doas chown -R ${USER}:${USER} .
#+end_src

***** umount the file

#+begin_src sh
doas umount ~/mnt
#+end_src

***** close the luks container

#+begin_src sh
doas cryptsetup luksClose luks
#+end_src

***** free the loop device

#+begin_src sh
doas losetup -d /dev/loop0
#+end_src

***** open luks encrypted container

#+begin_src sh
doas losetup -f
doas losetup /dev/loop0 disk.iso
doas cryptsetup luksOpen /dev/loop0 luks
doas mkdir -p ~/mnt
doas mount /dev/mapper/luks ~/mnt
#+end_src

***** umount luks encrypted container

#+begin_src sh
doas umount ~/mnt
doas cryptsetup luksClose luks
doas losetup -d /dev/loop0
#+end_src

*** Openbsd
**** encrypted device openbsd
***** list disks

list disknames

#+begin_src sh
sysctl hw.disknames
#+end_src

Detailed Hardware Model & Size Information

#+begin_src sh
dmesg | grep -E '^(sd|wd|nvme|cd)[0-9]'
#+end_src

list active softraid volumes

#+begin_src sh
doas bioctl softraid0
#+end_src

***** use dd to create a 128mb disk image

#+BEGIN_SRC sh
dd if=/dev/zero of=disk.img bs=1M count=128
#+END_SRC

***** attach vnd loopback device

list attached loopback devices

#+begin_src sh
doas vnconfig -l
#+end_src

attach disk.img to a vnd loopback device

#+BEGIN_SRC sh
doas vnconfig vnd0 disk.img
#+END_SRC

check the disk.img is attached

#+begin_src sh
doas vnconfig -l
#+end_src

***** initialize MBR and RAID partition on vnd0

Initialize default MBR partition table:

#+BEGIN_SRC sh
doas fdisk -iy vnd0
#+END_SRC

Write a disklabel spanning all free space as a RAID partition

#+BEGIN_SRC sh
echo 'RAID *' | doas disklabel -wAT- vnd0
#+END_SRC

***** bioctl

initialize softraid crypto volume

Passphrase authentication

#+BEGIN_SRC sh
doas bioctl -c C -l vnd0a softraid0
#+END_SRC

Note the softraid pseudo-disk device name created in the output (e.g., sd2).

Attach an existing volume later:

#+BEGIN_SRC sh
doas bioctl -c C -l vnd0a softraid0
#+END_SRC

***** newfs

Initialize an OpenBSD disklabel on the softraid volume (~sd2~) spanning partition ~a~:

#+BEGIN_SRC sh
doas disklabel -wA sd2
#+END_SRC

check the partion exists

#+begin_src sh
ls -l /dev/rsd2a
#+end_src

Format partition ~a~ with FFS (Fast File System):

#+BEGIN_SRC sh
doas newfs /dev/rsd2a
#+END_SRC

***** mount

#+BEGIN_SRC sh
mkdir -p ~/mnt
doas mount /dev/sd2a "${HOME}/mnt"
#+END_SRC

change the permissions

#+begin_src sh
doas chown -R "${USER}:${USER}" "${HOME}/mnt"
#+end_src

Verify mount status:

#+BEGIN_SRC sh
df -h ~/mnt
#+END_SRC

***** unmount

Unmount the file system

#+begin_src sh
doas umount "${HOME}/mnt"
#+end_src

detach the softraid crypto volume

#+begin_src sh
doas bioctl -d sd2
#+end_src

unconfigure the loopback device:

#+BEGIN_SRC sh
doas vnconfig -u vnd0
#+END_SRC

** Build
*** Cargo Initialization
**** Initialize the Project

Run cargo init to generate the necessary Rust configuration files and directory structure within the current folder.

#+begin_src sh
cargo init .
#+end_src

Note: This command creates a Cargo.toml file and a src/ directory with a default main.rs.

**** Staging Project Files

This will automatically create a git repository

Once initialized, you need to track the following essential files in your git repository:

#+begin_example
.gitignore
Cargo.toml
src/
#+end_example

**** Git Setup

Stage all the newly created files:

#+begin_src sh
git add .
#+end_src

Finalize the initialization with an initial commit:

#+begin_src sh
git commit -m 'project init'
#+end_src
